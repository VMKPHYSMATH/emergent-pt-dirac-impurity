# PT-Dirac finite-U NH-NRG adapter

This is a **first controlled adaptation** of the Burke/Mitchell non-Hermitian
NRG strategy to the frozen projected Anderson impurity used in
“Emergent PT Symmetry and Exceptional Points in a Driven Dirac Impurity.”

It implements a charge-conserving but pseudospin-mixing finite-`U` model,

\[
H_{\rm imp}=\epsilon_d(n_++n_-)+Un_+n_-+\Delta_{\rm eff}(n_+-n_-)
 +(\Delta_{\rm coh}+i\Gamma_{\rm PT})
 (d_+^\dagger d_-+d_-^\dagger d_+),
\]

coupled diagonally to a two-flavour Wilson chain. The bath is generated by a
numerical star-to-chain transformation for

\[
\rho(\omega)=\frac{r+1}{2D}|\omega/D|^r,
\]

so `bath_exponent = 0` gives a flat band and `bath_exponent = 1` gives the
Dirac/pseudogap test.

## What is already implemented

- finite `U` Anderson impurity;
- local complex-symmetric PT channel-conversion kernel;
- charge-only block diagonalization, because the local conversion breaks
  pseudospin/`S_z` conservation;
- left/right eigensystems and pairwise biorthogonal normalization;
- `LowRe`, `LowMag`, and `LowReMag` truncation choices;
- arbitrary power-law Wilson chain from logarithmic star discretization;
- complex many-body level-flow output;
- propagation of impurity creation and annihilation operators;
- a zero-temperature **kept-space biorthogonal Lehmann diagnostic**;
- spectral-weight sum-rule output, residuals, biorthogonality errors, and the
  minimum paired left-right overlap.

## Important limitation

The exported `kept_space_lehmann.csv` is **not yet a complete-basis or FDM-NRG
spectrum**. NRG truncation makes a final-iteration kept-space Lehmann sum
incomplete. The file `lehmann_sumrule.csv` quantifies that missing weight.
Use the curve initially as a convergence diagnostic only.

A publication-quality spectrum requires an Anders-Schiller complete basis or
FDM-NRG extension with the corresponding non-Hermitian left/right density
matrix. The many-body fixed-point flow is the primary reliable output of this
first adapter.

## Exact EP warning

The upstream NH-NRG method assumes a complete biorthogonal eigenbasis inside
each symmetry sector. At an exact Jordan point,
`<L|R> -> 0` and that assumption fails. Start with a small physical causal
 detuning, for example

```toml
delta_coh = 0.001
beta0 = 0.49
```

and approach `beta0 = 0.5` from both sides. The code aborts when a paired
overlap falls below `overlap_floor` rather than silently normalizing a singular
basis.

## Install Julia on the M2 Mac

Install Julia 1.11 for Apple Silicon, then from this directory run:

```bash
julia --project=. run_pt_dirac_nhnrg.jl --config config/example.toml
```

For the first near-EP scan:

```bash
./scripts/run_macos.sh
```

The default `nkeep=240`, `iterations=30` setup is intentionally conservative
for a fanless M2 MacBook Air. After the first clean run, test

- `nkeep = 240, 400, 600`;
- `Lambda = 2.0, 2.5, 3.0`;
- `sort_type = LowRe, LowMag`;
- `bath_exponent = 0, 1`;
- `Gamma_PT = 0` controls by setting `g_gamma = 0`.

## Outputs

- `complex_level_flow.csv`: rescaled complex many-body levels versus iteration;
- `wilson_chain.csv`: numerical chain coefficients;
- `kept_space_lehmann.csv`: preliminary retarded Green-matrix diagnostic;
- `lehmann_sumrule.csv`: completeness check for the truncated Lehmann sum;
- `RUN_SUMMARY.txt`: parameters and numerical warnings.

## Physical conventions

The default parameter path is

\[
\Delta_{\rm eff}=0.075+0.05\beta_0,\qquad
\Gamma_{\rm PT}=0.20\beta_0,
\]

with the symmetry-reduced core point at `beta0=0.5`.

`frame = "relative"` subtracts the common co-decay and is the cleanest choice
for fixed-point-flow comparison. `frame = "passive"` adds
`-i gamma_common (n_+ + n_-)` and enforces
`gamma_common >= abs(Gamma_PT)`. The latter is a finite-`U` effective-kernel
choice and should not be confused with a microscopic Wilson-chain embedding.
