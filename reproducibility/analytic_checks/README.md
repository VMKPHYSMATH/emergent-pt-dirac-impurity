# Restored analytic identities

Run:

```bash
python3 contact_and_smith_identity_check.py
```

The standard-library script checks, by exact sparse-polynomial arithmetic,
the determinant factorization of the restored four-contact finite-\(U\)
closure, its folded \(2\times2\) form after clearing denominators, the
shared-denominator ratio, and the algebra behind the center Smith-delay
pre-EP ratio.

The test does not enlarge the scientific scope.  The quadratic four-contact
system is exact for the projected one-particle kernel.  The finite-\(U\)
matrix identities are exact only within the explicitly stated local
Feshbach closure, and the Smith ratio is path-specific.
