# Code and data uploads only

Upload only reproducibility scripts, numerical inputs and outputs, figure-generation assets and validation documentation to GitHub. Do not upload manuscript TeX, manuscript PDFs, or editorial letters.

Before a release, run `python reproduce.py --verify-stored` and the relevant reruns. Review scientific scope and choose a new fixed release and Zenodo version for changed code/data. Do not reuse an older fixed DOI for changed bytes. Update manuscript data-availability statements separately in the private author package.

Historical repository files and releases are not removed by this revision. No merge, release, deposit or journal submission is recorded here.
